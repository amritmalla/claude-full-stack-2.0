# AI-Native Engineering

AI-native engineering uses AI systems as active collaborators across planning, implementation, review, testing, documentation, and operations. It is not just code generation. It is a way of making engineering work more structured, inspectable, and repeatable.

## Principles

- Give AI agents clear context, constraints, and success criteria.
- Prefer workflows that produce verifiable artifacts.
- Keep humans responsible for judgment, risk, and accountability.
- Use AI to explore alternatives, accelerate execution, and improve documentation.
- Design systems so agent-generated changes can be reviewed, tested, and traced.
- Ship skills as invocable recipes with defined inputs and verifiable outputs, not prose prompts an agent merely reads.

## Practical Focus

AI-native engineering works best when teams invest in:

- Clear repository structure
- Strong tests and quality gates
- Reusable prompts, skills, and workflows
- Operational runbooks
- Documentation that captures decisions and tradeoffs
