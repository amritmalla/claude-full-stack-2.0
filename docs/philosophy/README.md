# Philosophy

The beliefs behind this repository — why it is structured as invocable skills and workflows rather than a prompt collection.

- [Full Stack 2.0](full-stack-2.0.md) — software engineering as an integrated product, platform, and operations discipline.
- [AI-Native Engineering](ai-native-engineering.md) — AI agents as active collaborators across the engineering lifecycle.
- [Production Engineering](production-engineering.md) — building software that survives real users, failures, and operational pressure.
- [Operational Excellence](operational-excellence.md) — running and improving systems with discipline.
